解析几何 上4/4次 · 必考

置信度 95%

📊 趋势：24上出现2题（Q2两平面位置+Q6曲面类型），是所有模块中上半年最稳定的。26上至少1题，大概率2题。

已考过的子类型 直线与平面位置(21上) 空间对称(23上) 两平面关系(24上) 二次曲面类型(24上)

🎯 ⚠️ 未考方向：①点到平面距离公式 ②双曲抛物面(马鞍面)识别 ③直线与直线的位置关系

📌 26上重点：
→ 二次曲面识别：z=ax²+by²同号→椭圆抛物面，异号→马鞍面
→ 点到平面距离：d=|Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)——从未考过
→ 法向量核心地位：n=(A,B,C)决定平面的一切位置关系

矩阵 上4/4次 · 必考

置信度 95%

📊 趋势：21上Q6→22上Q6→24上Q4+Q5（2题！）。矩阵在24上爆发，26上可能回归1题。

已考过的子类型（点击展开） 零空间维数(21上) 矩阵乘法(22上) 特征向量(24上) 基/秩/可逆(24上)

🎯 ⚠️ 未考方向：①特征值λ具体数值 ②二次型与正定性 ③矩阵方程求解

📌 26上重点：
→ 特征值计算：解|A-λI|=0→λ值→代入求特征向量
→ 秩的判断：n-rank(A)=基础解系维数=自由变量个数
→ 矩阵可逆⇔det≠0⇔满秩⇔行/列线性无关⇔特征值全不为0

行列式 上3/4次 · 连续3次

置信度 85%

📊 趋势：22上Q3→23上Q4→24上Q1。连续3次上考试都有行列式！此趋势极可能延续到26上。

已考过的子类型 展开式系数(22上) 成比例⇒=0(23上) 对称行列式(24上)

🎯 ⚠️ 未考方向：①范德蒙行列式 ②伴随矩阵A*求逆 ③克拉默法则

📌 26上重点：
→ 行列式=0速判：两行/列成比例→直接=0（不要展开）
→ 含参展开：按零最多的行/列展开→多项式→解方程
→ |AB|=|A||B|：利用乘法性质绕开矩阵乘法

向量 上3/4次

置信度 80%

📊 趋势：22上Q2→23上Q3+Q6（2题！）→24上缺席→24下Q3。上考试偏好向量，24上缺席是例外。

已考过的子类型 内积展开+垂直(22上) 运算种类(23上) 几何表示(23上)

🎯 ⚠️ 未考方向：①叉积计算与方向判断 ②施密特正交化 ③线性相关性判断

📌 26上重点：
→ 叉积a×b：结果⊥a且⊥b，右手定则判方向——从未考过
→ 共面条件：(a×b)·c=0⇔混合积为零
→ ❌向量不能除法：每次向量题都可能出现的陷阱

极限 上仅2/4次

置信度 75%

📊 趋势：21上缺席→22上Q1→23上Q1→24上缺席。上考试中极限只在一半的年份当Q1！与下考试(7/8次)差异显著。

已考过的子类型（上考试） 有界性×无穷小(22上) 根式有理化(23上)

🎯 若出现：∞-∞通分法 or 0·∞化商法（上考试从未考过这些新子类型）

📌 26上重点（若出现）：
→ 因式分解+约分：上考试极限题偏基础
→ 等价无穷小替换：只在乘除结构中使用

概率统计 上2/4次 · 缺席2次

置信度 70%

📊 趋势：21上Q5→22上Q4→23上缺席→24上缺席。连续2次上考试缺席！但24下Q5首次考二项分布——新趋势可能影响26上。

已考过的子类型 骰子古典概型(21上) 独立事件乘法(22上)

🎯 若回归：①二项分布计算P(X=k) ②条件概率P(A|B)——两个都从未考过

📌 26上重点（若出现）：
→ 古典概型：枚举法+C(n,k)——基本功
→ 事件运算：P(A∪B)=P(A)+P(B)-P(AB)

连续与可微 上2/4次 · 缺席3次

置信度 70%

📊 趋势：21上Q2+Q4（2题！）→22上缺席→23上缺席→24上缺席。连续3次上考试缺席。整体也连续6次未考，极饥渴。

🎯 若回归：①导数定义lim[f(x)-f(0)]/x ②连续⇏可导反例 ③闭区间⇒一致连续

📌 26上重点（若出现）：
→ 导数定义式：f'(x₀)=lim[f(x₀+h)-f(x₀)]/h
→ 经典反例：|x|在x=0连续但不可导
→ 一致连续：闭区间连续⇒一致连续
